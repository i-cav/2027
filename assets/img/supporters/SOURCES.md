# Supporter logos

These logos are served locally and retain their original proportions.
The page uses the same logo space for every organization, with width adjustments to balance the different shapes.

- AWS: the inline logo from <https://aws.amazon.com/>, with `viewBox` capitalization normalized for a standalone SVG.
- TNO: <https://www.tno.nl/publish/pages/1547/tno.svg>, using the blue `#123EB7` from the official <https://www.tno.nl/publish/library/57/tno_logo.png> for display on white.
- VERSEN: <https://www.versen.nl/assets/img/logos/VERSEN-logo.svg>, offered on <https://www.versen.nl/contents/about/logos>.
- CPEC: <https://www.perspicuous-computing.science/wp-content/uploads/2019/11/Logo_CPEC_final_RGB.png>, from <https://www.perspicuous-computing.science/>.
